# Homepage pixel crew

Source: Sprite Pack 3 by GrafxKid, supplied in `Sprite Pack 3.zip`.
Official page: https://grafxkid.itch.io/sprite-pack-3
License: CC0 1.0 Universal; the original LICENSE.txt is retained here.

The original PNG sheets are unchanged, with filenames normalized for website URLs.
Each frame is 32 by 32 pixels. The homepage displays frames at integer scales
with pixelated rendering, using CSS frame and scene animations.

Selected characters: Gum Bot (idle/walk), Geralt (idle/pickup/carry/run/victory),
and Robot J5 (idle/run/jump/laugh). The scene is confined to the hero divider.
It respects the existing pause button, reduced-motion preference, scene-motion
setting, visibility and offscreen suspension.

Markup: includes/pixel-workshop.php
Styles: src/pixel-workshop.css, bundled into assets/2026/public.css
