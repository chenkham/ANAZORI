# Inauguration and Youth Parliament character artwork

## Files

- `genie-inauguration77.png` — 1257 × 1475, transparent PNG. Used for Inauguration.
- `phoenix-microphone77.png` — 1447 × 1087, transparent PNG. Used for Youth Parliament. An inline SVG viewport trims the transparent side margins when displayed; the PNG is unchanged.

Both characters appear in the homepage programme, and in event cards/details when the event has no custom cover photo.

## Sources and rights

Genie was downloaded from https://mail.1papacaio.com.br/images/pngs/disney/aladdin/aladdin-genio-clipart-004.png (gallery: https://mail.1papacaio.com.br/atividades/png-imagens-transparentes/png-disney/png-disney-aladdin).

Phoenix Wright's source image was downloaded from https://image.pngaaa.com/581/3189581-middle.png (page: https://www.pngaaa.com/detail/3189581). Its baked-in checkerboard was removed and its pointing hand changed to hold a microphone using the built-in imagegen tool with transparency enabled. No CLI fallback was used.

PNGAAA labels its Phoenix reference for non-commercial use. Genie is a Disney character; Phoenix Wright is a Capcom character. These sources do not establish an unrestricted or commercial reuse licence for the underlying characters. No such licence or official endorsement is claimed.
